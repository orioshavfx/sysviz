macOS cava alternative

Your system sound,
as a terminal visualizer.

sysviz is a terminal audio visualizer for macOS in the spirit of cava. It listens to the whole system mix through Core Audio, so it reacts to any app. No BlackHole, no drivers, no routing.

brew tap orioshavfx/tap
brew install sysviz
git clone https://github.com/orioshavfx/sysviz.git
cd sysviz && sh install.sh

Requires macOS 14.2 or later. Run sysviz, press q to quit.

What it does

System audio, no setup

Captures the default output with a Core Audio process tap. Works with Music, browsers and games alike.

64 log-spaced bands

40 Hz to 16 kHz on a logarithmic scale, with per-band adaptive peaks so quiet parts still move.

Pure terminal

Plain white block glyphs that fill the window and follow its size. No dependencies and no GUI.
